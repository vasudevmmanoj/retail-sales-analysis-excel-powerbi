# Retail Sales Analysis | Excel & Power BI

## 📊 Project Overview

An end-to-end **Retail Sales Analysis** project using **Microsoft Excel and Power BI**.

The project covers data cleaning, data validation, statistical analysis, dashboard creation, and interactive Power BI visualization.

## 🎯 Objectives

The project analyzes retail data to understand:

- Sales performance
- Profit performance
- Product category performance
- Regional performance
- Order status distribution
- Sales trends over time

## 🛠️ Tools Used

- Microsoft Excel
- Microsoft Power BI Desktop
- Power Query
- DAX
- PivotTables
- PivotCharts
- Excel Data Analysis ToolPak

## 📌 Work Completed

### Excel

- Data cleaning and preparation
- Missing-value checking
- Data validation
- PivotTable analysis
- Descriptive statistical analysis
- Correlation analysis
- Excel dashboard
- Slicers and charts

### Power BI

- Data import and transformation
- Data type correction
- DAX measures
- KPI cards
- Sales trend visualization
- Profit by product category
- Profit by region
- Order status analysis
- Interactive slicers

## 📈 Dashboard Features

The final Power BI dashboard includes:

- **Total Profit KPI**
- **Sales Trend**
- **Profit by Product Category**
- **Profit by Region**
- **Order Status Distribution**
- **Region Slicer**
- **Product Category Slicer**
- **Order Status Slicer**
